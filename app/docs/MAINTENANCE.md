## 验证方式

本轮 ESLint、28 项现有测试和生产构建通过，75 个作品素材引用有效。构建后检查部署目录不包含作品 PNG。

GIF 脚本的空输入、新备份成功、相同备份、不同备份冲突和编码失败五种隔离场景通过；编码器为模拟接口，验证的是文件保存与错误处理，未重新编码当前网站视频。

浏览器检查了桌面首页、About、Wilderness Rescue 和 NYBS，另检查了 390px / 320px 下的作品布局与灯箱打开关闭，所测页面没有横向溢出，灯箱 WebP 正常加载。手机手势仍由模拟事件测试覆盖，未做实机验证。

提交和同步状态以 Git 记录为准，网站发布状态以 GitHub Actions 的 deploy job 为准。PNG 备份随源码一起提交、推送后保存在在线仓库；推送 main 不会自动发布网站。
